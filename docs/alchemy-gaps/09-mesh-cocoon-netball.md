### Emitter-vs-trail mechanism (explicit)

- **Emitter:** a crisp 1–2 px closed cage drawn fresh each frame. **Topology (node graph) is
  held stable for one stamp period** (~0.2–1 s), **nodes jitter LIVE per frame** (small), and
  on each stamp event the geometry is **fully re-randomized** (node positions, ring/spoke
  counts within range, flavour, hue step). Stamps are audio-gated (r0) — cadence rises on hits.
- **Trail:** the ordinary feedback ghost beneath the crisp stroke; between stamps the ghost
  carries the shape (r0: "between stamps only the decaying ghost + a few live arms persist").
  v7's existing decay+blur buffer already provides this class of ghost — no warp change needed.
- **Eyes:** two SOLID orbs living inside the cage, ~14 % of frame apart, ballooning ~2× on
  hits, hue-snapping independently of the strands. They are the scene's anchor pair placed
  inside the motif — not a new element class.
- **Consolidated numbers:** ball dia 28–35 % of frame (elongated cocoon ~28 %×25 %, 1.5:1 on a
  diagonal; geodesic sphere small form 12–20 %); cells 8–60 px; rim spikes 10–15 with hooked
  tips; spokes ~12 (wagon wheel) up to 16–20 (p2); inner rings 2–3 (r0) up to 8–10 (p2);
  stamp cadence 0.2–0.3 s busy / topology ~1 s calm; rocking ~5°/s; strand hue step every
  ~1.5–2 s; 2 strand hues at once; exit = stamp-stop + ~1 s dissolve.

### Step 1 — `fCocoon`: the dreamcatcher cage as a new motif mode (smallest shippable slice)

Target: new function after `fFluffBall` (ends L803), before the `MODES` array; register by
appending to `MODES` (L825), `MODE_ALPHA` (L830 — append `0.55`, outline-class: rim/spoke
crossings pile up additively), and `MOTIF_BAG` (L924 — append `COCOON_ID, COCOON_ID`, weight
2 of 27, same rank as anemone/hexagram/tangle: a P1 motif recurring in both captures).
`scaleFor` needs no edit (0.4 default → ball radius `q5·0.38` ≈ 0.125–0.19 UV → dia ~25–38 %
of frame ✓ vs the 28–35 % measurement).

Construction, one 512-sample wave, ES5 like its siblings (fixed hash constants this step;
seeded re-roll arrives in step 3). Sample-band layout (hide connectors with `a.a = 0` at band
and segment boundaries, the file's standard trick — cf. L562, L681):

```js
// s in [0,0.22): RIM — one closed wobbly loop, 14 nodes (pentagon/hex-facet read)
// s in [0.22,0.50): 2 concentric inner rings, r = 0.62R and 0.34R, 10 nodes each
// s in [0.50,0.86): 12 SPOKES, rim node -> inner ring (the wagon-wheel read)
// s in [0.86,1.0): 12 short hooked SPIKES outward from rim nodes (tip kink ~0.25 rad)
function hsh(n) { var x = Math.sin(n * 127.1 + cocSeed) * 43758.5453; return x - Math.floor(x); }
```

Node positions = base polygon vertex + radial hash jitter `(hsh(node)−0.5)·0.24·R` (gives the
"crumpled" cells, 8–60 px at these scales) + **per-frame LIVE node jitter**
`(a.value1)·(a.q6)·0.5` perpendicular (p1: nodes jitter per frame; topology stable — the hash
part is stable, the value1 part is live). The dark "mouth" hole comes free: the inner ring at
0.34R leaves a hollow centre, and the hub is not filled. Rocking: rotate all angles by
`(a.q9)·0.15 + cocAng` (~5°/s at q9's 0.06 rad/s clock ✓). Colour: **two strand hues at once**
(r0) — even/odd nodes and alternate spokes take `q8 + cocHue` vs `q8 + cocHue + 0.30`, via
`orbCol` exactly like fNet L558–561; `cocHue = 0` this step. Alpha shaping per band: rim/rings
0.85, spokes 0.7, spikes 0.9 (crisp rim dominates, as in still_3.45). **Muted stays muted:**
colours come from the same `orbCol(q8…)` palette every sibling uses — no new saturation source;
the Pastel comp profile does the rest.

Composes with the directors automatically: motifPick dwell/crossfade, q4 dip/flash, q5 size
pulse, centre drift q2/q3. Gated entirely behind `q30 == COCOON_ID` — revert = remove the two
bag entries (soft-kill) or revert the commit.

### Step 2 — the orb EYES: re-anchor the existing pair inside the cage

Target: a new coupling block **inserted AFTER the `__ALC_FORCE` hook (L1136–1140) and before
`return t;` (L1141)** — this is deliberate: it keys off the EFFECTIVE `t.q30`, so a selfrender
pin exercises the eyes too (couplings keyed off `mCur` earlier in frame() stay dead under a
pin — verified against the hook's position).

```js
// COCOON EYES (A2): both anchors live INSIDE the ball, ~0.07 UV each side of centre.
var mEff = Math.floor((t.q30 || 0) + 0.5);
cocAmt += ((mEff === COCOON_ID ? 1 : 0) - cocAmt) * Math.min(1, dt * 0.6);
if (cocAmt > 0.01) {
  var ca = cocAmt * (1 - corridorAmt);          // never fight the corridor override
  var eAng = 0.2 + cocAng * 0.3;                 // near-horizontal "eyes", per-stamp jitter
  var ex = 0.07 * Math.cos(eAng), ey = 0.07 * Math.sin(eAng);
  t.q21 += (t.q2 + ex - t.q21) * ca;  t.q22 += (t.q3 + ey - t.q22) * ca;
  t.q23 += (t.q2 - ex - t.q23) * ca;  t.q24 += (t.q3 - ey - t.q24) * ca;
  t.q25 = Math.max(t.q25, 0.9 * ca);             // both eyes present for the ball's life
  t.q14 = Math.max(t.q14, 0.9 * ca);
}
```

Eye separation 0.14 UV ≈ p0's ~90 px/640. Radius: leave q7 alone — base 0.06 with the existing
beat balloon covers p0's 24→48 px eyes, and the balloon-on-hits + independent hue offsets are
already in the shape factories (nothing to build). **Tether suppression:** in waves[2]
point_eqs, multiply the final alpha (L1284) by `(1 - 0.85 * cocAmt)` — `cocAmt` is closure
state, readable there like `accLine` is in waves[1]; the refs show no line between the eyes.
Gated behind `cocAmt` (zero when the mode is not up) → individually revertible.

### Step 3 — stamp cadence: audio-gated topology re-roll + crisp-over-ghost envelope

Target: same post-hook block (frame side) + `fCocoon` (it already reads `cocSeed`/`cocEnv`).
In the block, when `mEff === COCOON_ID`:

```js
var dueMin = time - cocStampT > 0.25;            // r0: 0.2-0.3 s busy cadence
if ((f > 0.6 && dueMin) || time - cocStampT > 1.2) {   // p1: topology ~1 s calm
  cocStampT = time;
  cocSeed = Math.random() * 1000;                // full re-randomize (r0)
  cocAng = (Math.random() - 0.5) * 0.8;
  cocSizeMul = 0.8 + Math.random() * 0.45;       // dia range 25-38 %
  if (Math.random() < 0.4) cocHue += (Math.random() < 0.5 ? -1 : 1) * (0.08 + Math.random() * 0.14);
}
cocEnv = Math.exp(-(time - cocStampT) * 2.2);
```

`fCocoon` uses `R = (a.q5) * 0.38 * cocSizeMul` and multiplies its alpha by
`(0.45 + 0.55 * cocEnv)` — fresh stamps crisp, then the live stroke thins to "a few live arms"
over the feedback ghost (r0's measured look). The hue step lands p0's "strand hue snaps every
1.5–2 s" without touching the global q8 clock (B7 is another doc). Beat source: `f` from the
existing `beat` flash (in scope at the insertion point — L994 uses it). All state closure-only.
Revert = one commit; the step-1 cage still works with the fixed seed if this is reverted.

## 5. Risks & rollback

- **Risk (1) — shape budget:** the eyes are the EXISTING orb pair (shapes[0..3]) re-anchored
  via q21..q24; this doc adds NO shapes and NO filled beads. The removed bead-row failure
  (bad7755) was additive ring-beads *marching along a rail* re-stamping into caterpillar
  tubes; the cocoon's rings/spikes are stationary, re-stamped in place, and mostly
  non-marching — a different regime. Nothing here uses dots (waves render lines; the ~2 px
  fixed dot limitation is irrelevant).
- **Mode-7 rejection history (note L515–519):** a chaotic {13/5} star-art spray was rejected
  ("chaotic"), a rigid crosshatch rejected ("does not exist in original"). The dreamcatcher
  cage is ORDERED (rim + rings + spokes — r0's explicit decomposition), which is why step 1
  ships that flavour and the noisier crumple-cocoon waits for step 4 behind its own flag.
  Self-render before showing the user; if the crumple flavour reads chaotic, set its
  probability to 0 (one line) without losing the family.
- **Orb staging interplay (doc 07):** doc 07 restructures orb paths into posts/slides. The eye
  override lerps whatever upstream q21..q24 exist (same contract the corridor override relies
  on, L1119–1122) — it composes with either staging. Land order doesn't matter; if both land,
  re-render once to confirm.
- **Rests (B6):** the eye override holds both orbs visible during a cocoon dwell, temporarily
